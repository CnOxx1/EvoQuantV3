## 摘要

多数量化技术栈从**策略**出发。而在加密货币市场中行动的公开大语言模型（GPT、DeepSeek、GLM、Gemini 一类智能体）往往更早失败：它们缺少一个**完整、诚实、可审计的市场认知底座**。我们提出一个匿名化的**金融世界模型运行时**，将异步多波段证据编译为时点安全（point-in-time, PIT）的世界状态包（world bundle）。认识论观测 \(O_{j,t}=(x,\tau,q,g,r)\) 与编译算子 \(\Pi_t\) 生成 \(\mathcal{F}^{\mathrm{AI}}_t\)；完整性、诚实性 \((B,U,H)\) 与 WMI/ACWMI 支撑类型化的弃权契约；证据 ID 使行动可审计。

在**相同**的 100 个样本外（OOS）资产日上，对四个现场公开 LLM（温度 \(0\)）做三臂行为阶梯实验：Compiled（编译契约）稀薄世界弃权率 \(1.0\)；Ungated（同内容、无硬标志）均值 \(0.68\)（范围 \(0.43\)--\(0.86\)）；Raw（原始）\(0.04\)--\(0.75\)。披露有帮助，但依赖厂商；类型化布尔量可跨厂商强制全拒绝，而在 Ungated 下仍行动的模型在稀薄支撑上亏损。一项非交易的 grounding（接地）任务呈现同样的不对称：有编译包时，模型近乎完美识别缺失证据波段（F1 \(0.96\)--\(1.00\)）；仅有原始喂入时，F1 坍缩至 \(0.00\)--\(0.29\)。经济 CE 是次要的、用于检验内容非空的探针——不是策略“圣杯”。我们将运行时架构（采集器、vintage 存储、BandPIT 时钟、bundle schema、LLM 适配器）作为面向 ICAIF 的系统贡献加以详述。

**CCS 概念**：人工智能；机器学习；应用计算～经济学  
**关键词**：世界模型、公开 LLM、AI 智能体、加密货币、时点安全、弃权、可信 AI、市场认知、系统

## 1 引言

公开大语言模型越来越多地被要求分析或交易加密市场。瓶颈并不是又一个 alpha 信号，而是**理解**：在决策之前，智能体需要一个**完整**（缺失被披露）、**诚实**（过期或角色不一致的证据被门控）、**可审计**（行动绑定到证据）的市场世界。场所碎片化、衍生品、链上资金流、新闻与宏观 vintage 以不兼容的时钟到达。生成式世界模型与工具型金融智能体通常假定存在可用的观测流；加密智能体往往并没有。

**论点。** 我们为公开 LLM 构建市场**世界模型运行时**：将原始多波段证据编译为 PIT 安全的认知包，供 GPT / DeepSeek / GLM / Gemini 一类模型调用。策略指标是次要探针，用于检验世界是否有内容——不是产品目标。口号是：**量化从策略出发；本运行时从理解出发。**

**我们主张什么（以及不主张什么）。** RQ1 检验类型化世界接口能否在现场公开 LLM 上**强制**世界条件弃权——这是运行时契约，而非声称模型能从原始 tick 自发发现稀薄性。RQ2 检验编译后的波段字段相对同输入动量是否经济上非空。我们不主张无条件交易 alpha，也不主张 Dreamer 式生成模拟器。

**贡献。**

1. **认知语义。** 认识论观测、编译 \(\Pi_t\)、滞后重构界、完整性/诚实性字段、WMI/ACWMI 弃权、证据绑定行动。
2. **匿名化运行时架构。** 感知 vintage 的采集器、BandPIT 前收盘时钟、质量标注的 bundle、可用性冲击 \(O_t\)、OpenAI 兼容的多厂商适配器，以及冻结的 Compiled / Ungated / Raw 消费协议。
3. **现场三臂验证。** 四个现场公开 LLM 在相同 100 日样本上：Compiled 强制稀薄世界弃权 \(1.0\)；Ungated 软判断均值 \(0.68\)；Raw 常交易。Grounding 任务显示编译世界使认识论答案可核验（缺失波段 F1 \(0.98\) vs. 原始 \(0.12\)）；次要内容探针显示 vintage 波段字段经济上非空。

## 2 相关工作

**AI 中的世界模型。** 世界模型学习紧凑状态并常学习动力学。我们处理互补的**观测侧**问题：在动力学或 LLM 策略之前，先有一个 PIT 安全、质量标注的加密世界。我们主张的是生成式 WM 通常假定却缺失的系统层——不是 Dreamer/JEPA 模拟器。

**金融中的 LLM 智能体。** ChatGPT 收益预测、开放金融 LLM、记忆增强交易智能体、工具增强多模态智能体推进了智能体能力。智能体工具使用仍假定输入对齐。我们在冻结 schema 下做同模型 Compiled vs. Ungated vs. Raw 评估，估计量是**世界接口**，而非新的记忆模块或提示技巧。

**选择性预测与可信 AI。** 噪声下弃权可以是最优的。我们将拒绝绑定到世界质量，通过显式运行时契约，而非仅靠分类器置信度。

**PIT 度量与加密微观结构。** 宏观 vintage 与加密微观结构动机多波段编译。次要探针的 bootstrap 纪律遵循既有文献。资产定价机器学习相邻：我们为智能体验证编译内容非空，而非定价因子。

## 3 市场世界模型语义

**定义（认识论观测）。**  
\[
O_{j,t}=(x_{j,t},\ \tau_{j,t},\ q_{j,t},\ g_{j,t},\ r_{j,t})
\]  
分别为：取值、最新可用时间、质量、主视图门控、语义角色。省略 \((\tau,q,g,r)\) 的裸特征倾倒不是世界观测。

**定义（金融世界状态）。**  
\(W_t=\Pi_t(\mathcal{F}^{\mathrm{raw}}_t)\)，标量质量 \(q(W_t)\)（如 WMI/ACWMI）门控弃权；\(\mathcal{F}^{\mathrm{AI}}_t=\sigma(W_t)\)。

**定义（编译）。**  
\(\Pi_t=B_t\circ M_t\circ A_t\)：对齐时钟、施加诚实/缺失门控、组装波段视图。

**完整性、诚实性、质量。** Ready/limited/missing 计数披露覆盖。\(\mathrm{WMI}_t=B_t U_t H_t\)；ACWMI 支持状态条件门控。Compiled 契约将弃权标志（`should_ai_abstain`）与 `thin_world` 作为一等字段暴露。

**假设（有界滞后与增量）。** 波段 \(j\) 有最大观测滞后 \(\Delta_j\)；潜在状态增量满足 \(\|S_u-S_{u-1}\|\le\bar\delta\)。

**命题（滞后重构界）。** 在假设 1 下，
\[
\|\widetilde S_t-S_t\|
\;\le\;
C_{\mathrm{del}}\bar\delta
+C_{\mathrm{noi}}\varepsilon_t
+C_{\mathrm{miss}}m_t.
\]
编译不能消除延迟；它可以拒绝假装该界为零。

**直觉。** 把工具倾倒拼接起来的加密智能体，会把延迟与缺失静默吸进特征向量。上述命题使这些项显式化：更厚的原始载荷若诚实性坍塌，可能使重构更差。

**命题（编译 \(\neq\) 特征倾倒）。** 在没有 \(\Pi_t\) 的情况下扩大原始跨度，未必扩大可用的 \(\mathcal{F}^{\mathrm{AI}}\)：未门控的过期证据可抬高体量却降低诚实性/稳定性。

**命题（世界条件弃权）。** 若非弃权行动超过世界依赖成本 \(c_{\mathrm{abs}}(W_t)\)，贝叶斯行动是弃权；当成本随 WMI 递减时，弃权在世界质量上形成下集。

**命题（LOBO：内容 vs. 门控）。** 删除波段 \(j\) 通过内容通道与门控通道改变价值。经验上我们在未门控规则下报告内容份额，使探针指向字段非空。

**给系统审稿人的读法。** 编译与弃权命题说明为何运行时导出门控与弃权标志而非仅倾斜。LOBO 命题说明次要经济探针的正当性：若删除耐久波段不改变行动，则 bundle 是装饰性的。

**注记（不是生成式 WM）。** 我们不学习 \(p(s_{t+1}\mid s_t,a_t)\)。我们交付的是**状态编译器 + 弃权运行时**。

## 4 运行时架构

我们将匿名原型描述为分层系统对象（图 1）。源路径与产品名因双盲评审省略；接受后将发布匿名化制品。

### 4.1 分层设计

1. **数据层（采集器）。** 交易所、宏观、另类，以及（在可用时）新闻/链上/期权采集器写入感知 vintage 的历史：观测时间戳，以及宏观的 `available_at` vintage。
2. **存储层。** 嵌入式分析存储保存原始序列、合并市场面板与流水线输出（就绪度、WMI/ACWMI、论文世界快照）。
3. **逻辑层（编译）。** BandPIT 在前收盘时钟上重建波段就绪度；诚实/缺失门控与波段组装实现 \(\Pi_t\)；世界质量指数与可用性冲击 \(O_t\) 为一等公民。
4. **服务层。** 只读 API 向消费者提供质量标注的 AI bundle 与健康/就绪对象；新到达行无需重启采集器即可可见。
5. **消费层。** 冻结提示的 LLM / 规则智能体通过 OpenAI 兼容适配器（温度 \(0\)）在 Compiled、Ungated 或 Raw 处理下调用。

**表 1：匿名化模块图（系统视角）**

| 模块 | 职责 |
| --- | --- |
| Collectors | 以时间戳 / vintage 摄取多波段序列 |
| Vintage stores | 持久化原始、市场与分析对象 |
| BandPIT compiler | 前收盘就绪度、\(\Pi_t\)、WMI/ACWMI |
| Bundle builder | 组装完整/诚实/可审计的 JSON 世界状态 |
| Shock index \(O_t\) | 查询可用性中断，作为准外生杠杆 |
| LLM adapter | OpenAI 兼容聊天；冻结提示；温度 0 |
| Eval harness | Compiled/Ungated/Raw 采样、转录、表格 |

### 4.2 数据流：输入、处理、输出

表 2 端到端追踪运行时。**输入**：各波段采集器拉取公开市场数据——经 REST 的交易所 K 线/资金费率/持仓量、日频宏观风险指数（权益波动、美元指数）、稳定币流通总量，以及（可达时）新闻/链上/期权源——每行存储观测时间戳，宏观另存 `available_at` vintage。**处理**：对每个资产日，BandPIT 选取时间戳 \(\le(t{-}1)\,23{:}59\) 的最新观测，按各波段年龄阈值评为 fresh/stale/missing，将广度/稳定性/诚实性聚合为 WMI 与状态条件 ACWMI，导出内容倾斜（5 日宏观指数变化；7 日稳定币流斜率；收益动量），并记录可用性冲击 \(O_t\)。**输出**：约 3,990 行 PIT 面板（10 资产 × 399 日，约 50 列）、每日世界 bundle，以及支撑实验节的消费者转录/表格。

**表 2：运行时数据流（匿名化来源）**

| 波段 | 拉取（原始） | 发出（bundle） |
| --- | --- | --- |
| exchange | OHLCV K 线（1h/1d）、资金费率、持仓量、订单簿 | \(\mathrm{mom5}\)；波段状态/年龄；资金费率上下文 |
| macro | 权益波动与美元指数；vintage 宏观序列 | \(\mathrm{macro\_tilt}\)（5 日变化）；状态/年龄 |
| alternative | 稳定币流通总量 | \(\mathrm{alt\_tilt}\)（7 日流斜率）；状态/年龄 |
| news / on-chain / options / tokenomics | RSS、链浏览器、期权链（此处右删失） | status = `missing`，已披露 |
| payoff | 日收盘（外部参考） | 仅用于打分的收盘到收盘 \(r_t\) |
| derived | --- | \(B,U,H\)，WMI，ACWMI，`should_ai_abstain`，`thin_world`，\(O_t\)，`evidence_ids` |

### 4.3 PIT 前收盘时钟

对日历日 \(t\)，决策信息集在 \((t{-}1)\,23{:}59\) 重建。收益是同日历日收盘到收盘收益 \(r_t\)。这消除了波段状态与 vintage 宏观/另类内容中的同日前视。Bundle 在 `decision_asof` 中记录时钟；每次现场运行将 `timing_protocol` 钉在前收盘协议上。

表 3 列出字段组。列表 1 给出 OOS 面板上的紧凑 Compiled 示例：仅 \(2/8\) 波段就绪、WMI 低、`should_ai_abstain=true`，且 `evidence_ids` 将行动绑定到已披露波段/倾斜。Ungated 去掉硬布尔（与阈值）但保留数值 WMI/ACWMI 与完整性。Raw 仅保留 `mom5`（外加无信息噪声位）。

### 4.5 三信息臂与 LLM 适配器

- **Compiled（产品契约）：** 完整 bundle；冻结提示在 `should_ai_abstain` 为真时**要求**弃权。
- **Ungated（消融）：** 同内容/完整性/数值 WMI；**无**硬标志；软提示请模型自行判断稀薄性。
- **Raw（无世界模型）：** 仅 `mom5`；无质量指数或弃权指导。

行动 \(\in\{\mathrm{bullish},\mathrm{bearish},\mathrm{neutral},\mathrm{abstain}\}\)。理解指标优先稀薄世界弃权率与 EAR 代理，而非 CE。耐久档案波段：\(\{\mathrm{exchange},\mathrm{macro},\mathrm{alternative}\}\)；新闻/链上/期权右删失并披露为缺失（图 2）。适配器使用 OpenAI 兼容 chat completions；模型 ID 透传；凭证留在环境变量（永不进入制品）。

### 4.6 冻结提示契约

列表 2--3 摘录冻结的 Compiled 与 Ungated 契约（温度 \(0\)；行动 schema 相同）。唯一有意差异是硬弃权 vs. 软弃权。Raw 提示完全省略世界质量语言。

**列表 2：Compiled 契约（摘录）**

```
Decision rules (excerpt):
1. If world_model_index.should_ai_abstain is true
   OR the world is thin, you MUST "abstain".
2. Prefer band content over raw momentum
   (macro_tilt, alt_tilt are PIT-safe).
3. Rationale must be consistent with evidence_ids.
```

**列表 3：Ungated 软契约（摘录）**

```
Decision guidance (soft):
1. Judge whether missingness / low WMI/ACWMI
   makes action unsafe; you MAY "abstain".
2. Prefer band content when you act.
NO hard abstain boolean; NO forced policy.
```

**并非“只是指令跟随”。** Compiled 弃权部分是提示服从——而这正是**产品要求**：生产智能体在 \(q(W_t)\) 低时需要可强制的拒绝接口。Ungated 度量仅靠披露的软判断；Raw 度量常见的“仅价格信号”集成。可靠的 Compiled 拒绝是 SLA；自发的 Ungated 拒绝是加分项。

### 4.7 服务面与可复现性

服务层暴露消费者 harness 使用的只读对象：(i) 质量标注世界 bundle；(ii) 波段就绪度 / WMI--ACWMI 快照；(iii) 可用性冲击查询 \(O_t\)；(iv) 健康元数据，披露论文引擎或生产代理是否水合 ACWMI 输入。采集器与逻辑流水线可作为受监督作业运行；API 实时读存储，新编译行无需进程重启即可出现。评审中我们冻结提示、温度、行动 schema、IS/OOS 切分与采样种子；模型 ID 与 OpenAI 兼容 base URL 是配置，不是估计量。凭证永不进入已提交制品。接受后将发布含消费者 harness、冻结提示与表格复现脚本的匿名仓库。

## 5 实验

### 5.1 设置

PIT 面板约 399 日（≈13 个月）、10 个流动性标的、前收盘时钟、按时间切分 IS/OOS \(200/200\) 日。现场 RQ1：三臂均在**相同**的分层抽样 100 个 OOS 资产日上运行（同采样种子），温度 \(0\)，冻结提示，OpenAI 兼容网关。模型：`gpt-5.4-mini`、`deepseek-v4-flash`、`glm-5.2`、`gemini-3.5-flash-lite`。离线 mock 在无密钥下于完整 OOS 复现协议。稀缺/稀薄标签在 OOS 上按设计绑定：主检验是稀疏支撑下的诚实性，而非稠密世界交易赛马。

### 5.2 RQ1（主）：三臂现场行为

表 4 与图 3 是 headline 结果；所有臂共享相同的 100 个 OOS 资产日。在 Compiled 下，四个模型在每个稀薄世界日均弃权（thin-abs. \(1.0\)）；理由在 \(93\)--\(99\%\) 的日子引用世界字段。在 Ungated 下，平均 thin-abs. 降至 \(0.68\)（范围 \(0.43\)--\(0.86\)）：DeepSeek 与 GLM 高于 \(0.80\)，GPT 降至 \(0.63\)，`gemini-3.5-flash-lite` 降至 \(0.43\) 并交易。当 Ungated 模型行动时，它们亏损（跨模型 CE \(-1.04\) 到 \(+0.02\)）——软判断恰在强制有意义处失败。在 Raw 下，弃权率为 \(0.04\)--\(0.75\)，并有大量方向质量（表 5）。平均 \(\Delta\)CE（Compiled−Raw）\(=+1.07\) 最后报告：Compiled 在全弃权下 CE 为零，故差距主要反映 Raw 过度交易——不是圣杯。

| gpt-5.4-mini | 1.00 | 0.63 [.53,.72] | 0.04 [.02,.10] | +0.73 |
| deepseek-v4-flash | 1.00 | 0.81 [.72,.87] | 0.75 [.66,.82] | +1.22 |
| glm-5.2 | 1.00 | 0.86 [.78,.91] | 0.11 [.06,.19] | +1.04 |

### 5.3 RQ3：非交易认知——世界状态 grounding

认知底座应服务分析，而非仅交易/弃权决策。我们在每臂 50 个 OOS 资产日上增加现场 **grounding** 任务：模型须总结世界状态并回答 (i) 底层数据是否足以行动，以及 (ii) **哪些证据波段缺失**——这是有 PIT 真值的可核验问题。表 6：有 Compiled bundle 时，四个模型近乎完美识别缺失波段（F1 \(0.96\)--\(1.00\)）；有 Raw 时，F1 坍缩至 \(0.00\)--\(0.29\)。两臂大多判定数据不足（裸动量喂入显然稀薄），故区分性技能不是谨慎，而是**可核验的认识论**：只有编译世界让模型能说出**缺了什么**并被检查。这是命题“滞后重构界”中缺失项的分析侧对应物。

### 5.4 RQ2：编译内容非空

透明规则与动量共享收益输入，并加入 vintage 的 \(\mathrm{macro\_tilt}\) / \(\mathrm{alt\_tilt}\)。预指定 OOS 对比 mechanism − momentum：\(\Delta\mathrm{CE}=0.334\)（\(p=0.034\)；平稳 \(p=0.022\)）。LOBO：删除宏观或另类坍缩到动量（未门控规则下内容份额 \(1.0\)）。相对差距在 \(10\)--\(25\)bps 成本下存活；绝对 CE 对成本脆弱。2017--2026 审计在无 vintage 档案下未发现隐藏收益规则 alpha。

### 5.5 讨论与效度威胁

现场阶梯  
\(\mathrm{Abs}_C=1.0 > \mathrm{Abs}_U\approx 0.68 > \mathrm{Abs}_R\in[0.04,0.75]\)  
是产品证据：标记世界稀薄的认知底座诱导厂商稳定的拒绝；仅披露不完整；原始喂入过度行动。Ungated 下的跨厂商异质性（GLM \(0.86\) vs. Gemini \(0.43\)，Wilson CI 不重叠）正是类型化契约在生产中有价值的原因：软判断依赖模型，而 Compiled 拒绝稳定。RQ2 表明波段字段不是装饰。主张：**理解优先，策略其次。**

相对 FinMem / FinAgent 式系统，我们不提出新的记忆或工具路由器。我们提出那些智能体在市场喂入异步且质量异质时隐含需要的观测编译器。相对收益预测 LLM 研究，我们在 PnL 之前先打分拒绝与可审计性。

**效度威胁。** (1) **提示契约**——Compiled 拒绝部分是指令；Ungated 是软对照。(2) **稀薄档案**——OOS 上稀缺率 ≈1 强调诚实性，而非稠密校准。(3) **基线**——Raw 匹配常见稀薄集成；Ungated 是同内容对照。(4) **样本量**——每臂 100 现场日（报告 Wilson CI）；harness 支持完整约 2000 行 OOS 扫描。(5) **厂商路由**——网关与模型 ID 可变；提示/schema 冻结以便同模型对照。(6) **任务范围**——交易行动空间是粗粒度方向 schema；grounding 任务是首个非交易探针，更丰富的分析工作流仍开放。

## 6 面向 ICAIF 系统读者的设计理由

三项实现选择是有意的。

**导出门控，而非仅特征。** 静默特征库隐藏过期。通过把完整性、诚实性与 `should_ai_abstain` 放入 bundle，运行时使拒绝成为一等的、机器可读事件，而非自由文本道歉。

**前收盘 PIT 优于挂钟流式。** 日内流式演示看起来炫，但混淆前视。前收盘时钟保守且可审计：每个现场决策引用评审者可从面板重算的 `decision_asof` 戳。

**三臂而非单一排行榜。** 单一 Compiled-vs-holdout Sharpe 诱发圣杯读法。Compiled / Ungated / Raw 分离 (i) 类型化强制、(ii) 仅披露的软判断、(iii) 无世界模型——匹配团队实际集成 LLM 的方式。

## 7 局限

我们不主张生成动力学或无条件交易 alpha。新闻/链上/期权历史右删失并披露为缺失。稠密世界选择性预测赛马需要更厚档案。现场样本受预算约束（每臂 100 资产日）；harness 已支持完整 OOS 复现。Camera-ready 将恢复作者身份，并指向评审期间推迟的匿名仓库。

---

## 8 结论

公开 LLM 需要在决策前先有一个可**理解**的市场。我们贡献认知语义与匿名分层运行时——采集器、vintage 存储、BandPIT 编译、bundle 契约与 LLM 适配器——将异步加密证据变为完整、诚实、可审计的世界状态。现场公开 LLM 呈现三臂阶梯：Compiled 强制稀薄世界拒绝，Ungated 仅从披露部分恢复，Raw 常在稀疏支撑上交易。同一 bundle 使面向分析师的答案可核验（缺失波段 grounding F1 \(0.98\) vs. 原始 \(0.12\)），内容探针确认编译状态非空。策略仍位于理解的下游。
