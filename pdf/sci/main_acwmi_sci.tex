\begin{abstract}
Conditional asset pricing treats the investor's information set as given. In cryptocurrency markets that premise fails: evidence is asynchronous, multi-source, and intermittently unavailable. This paper formalizes \emph{information-set compilation} and measures world-model quality with an Adaptive Conditional World Model Index (ACWMI). Empirically, we populate a real multi-band archive---OKX exchange bars, macro vintages, alternative series, plus thinner news/on-chain/options/tokenomics snapshots---and construct a 400-day point-in-time panel (10 assets, 4{,}000 asset-days) aligned to Yahoo returns. Mechanism engines use only pre-$t$ history. Abstention thresholds are frozen in-sample. Out of sample, thick real PIT worlds dominate exchange-only thin worlds (CE $0.47$ vs $-0.01$). Leave-one-band-out on durable bands shows large CE losses from dropping macro ($-0.53$), alternative ($-0.53$), or exchange ($-0.34$). An IS-frozen ACWMI gate remains implementable (Sharpe $0.90$, CE $0.20$) but does not dominate ungated thick signals on CE. The production WMI$<0.2$ rule is mis-scaled for sparse archives (100\% abstention), illustrating why quality thresholds must be frozen to the information set's support. The contribution is a finance-native compilation theory plus a reproducible PIT identification protocol on a live multi-band laboratory.
\end{abstract}

\section{Introduction}

Modern asset pricing conditions on an information set $I_t$ \citep{fama1993,cochrane2005,gu2020,kelly2019,nagel2021}. The literature's discipline has focused on how $I_t$ is \emph{used}, not how it is \emph{compiled} from asynchronous, quality-heterogeneous evidence. Cryptocurrency markets make compilation first-order: venue fragmentation, leverage, options walls, unlocks, on-chain flows, and macro liquidity can map the same price path into incompatible states \citep{makarov2020,liu2022}.

This paper (i) formalizes Regime-Conditional Adaptive World Models (RCA-WM) and ACWMI, (ii) populates a real multi-band archive using the project's collectors, (iii) builds a point-in-time panel from history tables, and (iv) evaluates OOS economic value with frozen thresholds and leave-one-band-out identification.

\section{Theory}

Epistemic observations $O_{j,t}=(x,\tau,q,g,r)$ carry timestamps, quality, gates, and roles. Asynchronous lags induce a reconstruction bound with delay, noise, and missingness terms. Compilation maps raw filters $\mathcal{F}^{\mathrm{raw}}$ into AI-visible $\mathcal{F}^{\mathrm{AI}}$. ACWMI is the regime-conditional geometric mean of hierarchical breadth, stability, continuous honesty, signal integrity, and consistency. Abstention is Bayes-optimal when expected loss of every non-abstain action exceeds a world-dependent cost. Identification uses availability/coverage variation $O_t\to W_t\to A_t$.

\section{Data and PIT archive}

\subsection{Populated laboratory}
We bootstrap the project's split SQLite store (OKX-only exchange path; Binance/Bybit blocked in this environment):
\begin{itemize}
\item \textbf{Exchange:} $\sim$9.4k OKX klines / merged bars for 10 symbols, daily range 2025-06-30 to 2026-08-03; 2.4k funding rows.
\item \textbf{Macro:} 81k vintaged points (\texttt{available\_at} present), spanning decades to 2026-08-03.
\item \textbf{Alternative:} 89k points from 2017 onward (stablecoin/related series; Google Trends largely rate-limited).
\item \textbf{News / on-chain / options / tokenomics:} populated but mostly right-censored to collection day.
\item \textbf{\texttt{time\_slice}:} historically resolves klines; analytics snapshots remain sparse, so multi-band PIT is built from raw history tables via \texttt{build\_pit\_archive.py}.
\end{itemize}

\subsection{PIT panel}
For each date $t$ and asset, band status $\in\{\mathrm{ready},\mathrm{limited},\mathrm{missing}\}$ is inferred from the latest observation time $\le t$ and band-specific freshness thresholds. Breadth/stability/honesty and production WMI are computed with project code. Durable historical bands are $\{\mathrm{exchange},\mathrm{macro},\mathrm{alternative}\}$. Yahoo daily returns provide the payoff series; engines use only pre-$t$ returns.

\section{Empirical design}

Chronological IS/OOS split (200/200 days) at 2026-01-16. AC thresholds frozen on IS by Sharpe maximization with abstain rate $\in[5\%,55\%]$: $\mathrm{ACWMI}<0.35$ or $C<0.35$. Production WMI threshold $0.2$ is never tuned. Baselines: always-long, momentum, thick-ungated, simple outage, cascade, WMI, ACWMI. Economic value: annualized return/vol, Sharpe, CRRA CE ($\gamma=2$), max DD.

\subsection{\texttt{time\_slice} status}
Monthly \texttt{time\_slice} probes show historical kline readiness with sparse analytics snapshots. This motivates the hybrid design: raw multi-band history for $W_t$, \texttt{time\_slice} for logic-domain replay as snapshot density grows.

\section{What remains for JF/RFS}

\begin{enumerate}
\item Continuous multi-year collection so news/on-chain/options/tokenomics cease to be right-censored.
\item Logged institutional outages as $O_t$ (natural hard outages are rare inside a continuous OKX backfill).
\item Persist daily readiness/AI-context snapshots for pure \texttt{time\_slice} replay.
\item Recalibrate/freeze WMI thresholds on the archive's support before comparing to ACWMI.
\item External validity beyond ten liquid names.
\end{enumerate}

\section{Conclusion}

Information-set compilation is measurable. On a real multi-band PIT archive, thick worlds dominate thin worlds, and durable bands have large leave-one-out economic value. Selective ACWMI gating is implementable under frozen thresholds but is not CE-dominant versus ungated thick signals in this sample. The laboratory path to a top-finance paper is now concrete: keep collecting, snapshot daily, and replace right-censored bands with vintaged histories.
