# EvoQuant 纯数据层边界

## 运行目标

本版本仅负责从免费公共来源采集、清洗、标准化并持久化加密货币事实数据。数据层不输出交易信号、情绪结论、Regime、组合风险、AI 上下文或任何商业供应商的推断结果。

## 保留的对外数据域

| 数据域 | 主要公开来源 | 主表 |
|---|---|---|
| 行情、衍生品、订单流、盘口 | OKX 公共 API | `latest_tickers`、`latest_funding_rates`、`latest_trade_flow_bars`、`latest_orderbook_snapshots` |
| 宏观、新闻、链上、DeFi、稳定币 | FRED、RSS、DeFiLlama、Alternative.me | `macro_timeseries`、`news_articles`、`latest_onchain_timeseries`、`defi_tvl`、`stablecoin_chain_flows` |
| 期权、治理、Gas、Mempool、MEV、矿工 | Deribit、Snapshot、MetaMask、mempool.space、Flashbots、Blockchair | 对应 market SQLite 主表 |
| 公开地址与储备证明 | CryptoLabel、OKX Proof of Reserves | `address_labels`、`exchange_reserves` |

## 显式隔离

`logic_layer/` 的研究、因子、策略、风险、AI 与情绪模块不属于数据层产品契约；它们保留在 Git 基线 `pre-data-layer-cleanup` 之后的源码历史中，但不会由状态接口或纯数据运行入口对外暴露。商业供应商占位模块（ETF 流、钱包 PnL、社交情绪、全量鲸鱼归因、完整解锁日历）同样不在当前运行目录中注册。

## 运行入口

使用 `python scripts/run_public_data_layer.py` 仅运行保留采集器。每次运行后执行 `python scripts/audit_active_domain_freshness.py` 审计 SQLite 主表记录量与时间戳。
