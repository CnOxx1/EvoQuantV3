## 明确边界与后续处理

公开 CoinGecko 分类端点实际返回 865 个分类名称，但对资产逐条获取 `categories` 时，第 5 次请求出现 HTTP 429。因此程序将结果明确输出为 `partial_rate_limited`，已落库的 51 条分类仍保留，后续可分批续跑；不会把分类字典伪装成完整资产分类覆盖。CoinGecko 历史流通供应图属于 Enterprise 边界，当前没有接入。[1]

OKX 衍生品表保存的是已验证公共端点在采集时返回的原始窗口，不应被解读为无限期、全市场的历史档案。后续如扩展更长窗口，必须使用带进度、页大小与 `before/after` 游标的独立脚本，避免恢复旧的大而全任务入口。[2]

Bitcoin 链上历史当前只覆盖公开可验证的三项基础事实指标；它不等同于多链地址级归因，也不使用需要 API Key 的 Etherscan 或商业聚合源。Kraken 和 Coinbase 仅作为已实测的公共报价来源，未将具有地域或连通性不确定性的交易所声称为稳定依赖。[3] [4]

## 运行方式

```bash
# 全部稳定公共采集器（16 个）
.venv\Scripts\python.exe scripts\run_public_data_layer.py

# 限速、可恢复的资产分类小批次
.venv\Scripts\python.exe scripts\collect_free_asset_categories.py --limit 3 --pause-seconds 3

# 目录与记录量验证
.venv\Scripts\python.exe scripts\audit_active_domain_freshness.py
.venv\Scripts\python.exe scripts\verify_public_data_coverage.py
.venv\Scripts\python.exe scripts\summarize_free_data_expansion.py
```
