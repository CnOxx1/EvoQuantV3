# 公开来源核验记录

## 解锁日历：DefiLlama

- 页面：`https://defillama.com/unlocks`
- 2026-08-22 页面显示其追踪 368 个协议，并展示未来 7 日、30 日解锁统计、单协议解锁额、解锁占流通量比例、每日线性解锁与后续价格影响。
- 页面导航将 API 与 MCP 指向 `https://api-docs.defillama.com`，但页面同时展示高级订阅入口；在未核验对应程序化端点、速率与再分发条款前，不能把网页内容视为可稳定免费 API。

## BTC ETF 日度资金流：Farside Investors

- 页面：`https://farside.co.uk/bitcoin-etf-flow-all-data/`
- 页面公开 HTML 表格，字段包括日期、IBIT、FBTC、BITB、ARKB、BTCO、EZBC、BRRR、HODL、BTCW、GBTC 与日度总计，单位为百万美元。
- 已确认其可用于人工审计日度 BTC ETF 资金流；尚未发现对外承诺的结构化 API 或再分发许可，因此不能直接将网页抓取作为生产稳定数据源。后续仅能在条款明确允许后，采用带来源链接、延迟与失败降级的采集器。

## 地址标签：CryptoLabel

- 页面：`https://cryptolabel.io/`
- 页面声明可对 Bitcoin、Ethereum 与 Tron 地址进行无 API Key 的公开查询；响应包含标准化地址、账户类型、已知实体、标签类别、来源类型、检测方法、状态和浏览器链接。
- 该来源可作为“已知公开标签”的低覆盖、可解释补充，适合恢复地址页面与有限的交易所/服务实体标注；它不能替代 Arkham、Nansen 等商业全量实体图谱，也不能据此宣称地址所有权或“鲸鱼 PnL”。

## 社交情绪：Messari Signals

- 页面：`https://docs.messari.io/api-reference/endpoints/signal/sentiment/overview`
- 文档列出基于高关注度用户社交帖子、回复和转发构建的资产级指标，包括 0–100 情绪分数、情绪动量、近 7 日正/负/中性帖子占比和帖子量。
- 文档页面显式提供“Get API Key”和“Request API Access”，因此该来源不能被当作无授权公共数据。可作为后续商业授权后的数据契约候选，但当前应继续保持 `social_sentiment` 为 disabled。

## 解锁数据：Messari Token Unlocks

- 页面：`https://docs.messari.io/api-reference/endpoints/token-unlocks/token-unlocks-api`
- 文档列出资产、分配、单资产解锁事件、聚合解锁和归属计划五类正式端点，字段范围足以支持解锁事件与卖压研究。
- 文档同样显示“Get API Key”和“Request API Access”。同时，对 `https://api.llama.fi/unlocks` 的直接公开访问未得到可用结构化响应。因此可将 Messari 定义为授权接入候选；当前不应把 DefiLlama 网页表格或未验证端点作为生产免费解锁 API。

## 交易所储备：OKX Proof of Reserves

- 页面：`https://www.okx.com/en-us/proof-of-reserves`
- OKX 官方页面声明每月发布储备证明、公开链上钱包持仓，并为 22 种资产提供储备报告；页面链接到开源的验证工具与最新报告文件。
- 这为“OKX 官方 PoR 快照”提供了可验证的公开来源，可恢复范围限定为报告时间点的官方披露资产、储备比率与地址证明。它不能被扩展为所有交易所的实时净流入/净流出或全市场储备排名；生产采集应使用版本化证明文件，而非推断地址归属。
- 官方下载页 `https://www.okx.com/en-us/proof-of-reserves/download` 公开列出报告 ID、UTC+8 日期、zk-STARK v2 类型和 Reserves 文件类别。2026-08-22 可见的最新报告 ID 为 499955235，日期为 2026-07-07。这足以安全采集“报告元数据”；在下载文件的资产字段经结构化验证前，不得写入任何资产余额或计算 24 小时净流量。

## 钱包 PnL：Moralis Profitability

- 页面：`https://docs.moralis.com/data-api/data-features/data-enrichment/profitability-pnl`
- 文档说明其 PnL 基于链上 DEX swap 的加权平均成本法，当前覆盖 Ethereum、Polygon 与 Base，并明确仅提供已实现 PnL；未实现 PnL 需再结合余额和价格计算，且不包含 Gas 费用。
- 页面属于带 Pricing/Enterprise/数据 API 导航的商业服务文档，未证明存在可直接用于生产的无授权公共层。因此它是一个可解释的授权接入候选，而不是当前 `whale_pnl` 的免费替代；未取得有效 API 凭据前必须继续禁用。
