# 免费公共数据源核验记录

本记录保存 2026-08-22 对免费公共数据源的文档核验结果，供 EvoQuant 本机采集器实现、数据来源展示和合规归因使用。

| 来源 | 已核验的公开能力 | EvoQuant 适用数据域 | 使用约束 |
|---|---|---|---|
| DeFiLlama API | `/protocols`、链 TVL、稳定币、DEX 概览、收益池等公开端点 | DeFi、协议 TVL、DEX Volume、稳定币、Tokenomics 补充 | 高级分析端点属于 API Plan，不得将其当作免费功能 |
| FRED API | 经济时间序列、系列观察值、发布和分类查询 | 宏观利率、通胀、美元、信用利差等 | FRED API 需要遵循其 API Key 与使用条款；本项目优先保留已有公开市场替代源并可选配置 Key |
| Alternative.me Fear & Greed | `/fng/` 返回比特币恐惧贪婪值与历史 | 市场情绪基础因子 | 商业展示必须在数据旁显著标注来源和归因 |
| mempool.space REST | 推荐费率、内存池、区块、矿工和哈希率数据 | Mempool、矿工、网络拥堵 | 有速率限制；采集器应限频、缓存并处理 HTTP 429 |
| MetaMask Gas API | Ethereum 推荐 Gas 费用 | Gas/网络拥堵 | 作为无密钥备用源；应记录来源与采集时间 |
| Blockchair Ethereum Stats | 当前 Ethereum 链高度及网络统计 | Gas 备用区块高度、链网络概览 | 免费公共访问应控制请求频率 |
