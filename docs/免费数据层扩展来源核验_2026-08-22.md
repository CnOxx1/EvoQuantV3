# 免费数据层扩展来源核验

## 可直接接入的公开历史数据

| 数据 | 来源 | 免费可用字段与边界 |
|---|---|---|
| 永续资金费率历史 | Deribit `public/get_funding_rate_history` | 无认证的公共方法；按 PERPETUAL 合约返回小时级时间戳、1 小时/8 小时利率与指数价格。 |
| OKX 市场与衍生品快照 | OKX Public REST/WebSocket | 公共频道无需认证；可采集行情、K 线、订单簿、标记价格及公开衍生品字段。私有账户数据不属于数据层。 |
| 资产市场元数据 | CoinGecko `/coins/markets` | 文档标注 Demo/Keyless 层存在，返回 coin id、symbol、名称、价格、市值、排名、流通/总/最大供应与更新时间；按 250 个 ID 分页。 |
| 多交易所现货报价 | Kraken `Ticker`、Coinbase Exchange `products/{product_id}/ticker` | 两者均以无认证公开接口返回可观测的最新报价。当前实现仅采集已实测的 BTC/USD、ETH/USD，并保存 bid、ask、last、volume、来源 URL 与原始响应。 |
| 项目分类字典 | CoinGecko `/coins/categories/list` | Windows 实测无密钥返回 865 个分类名称。分类字典不等同于资产归类。 |
| 资产项目分类 | CoinGecko `/coins/{id}` 的 `categories` | 针对已落库资产增量请求，保存资产 ID、分类名称、采集时间与来源 URL；严格限速、可续跑。公开端点会返回 429，因此不能声称一次全量 250 资产的完整分类覆盖。 |
| 交易对映射 | 本地已采集 `exchange_data.db.market_info` | 从已有公开交易所市场信息派生 asset symbol—exchange—pair 映射；这是本地规范化结果，源市场信息仍保留于交易所原始库。 |

## 不纳入免费实现的端点

CoinGecko 历史流通供应图端点为 Enterprise Only，不能作为无付费、无密钥数据层来源。它只能作为未来获得授权后的可选补充，当前不会调用。

## 实施优先级

1. 将 Deribit 小时资金费率历史写入独立历史表；不混写为当前快照。
2. 扩展 OKX 公共历史 K 线、资金费率、OI、基差及清算可得字段，并以来源/时间/交易所作联合键。
3. 以 CoinGecko Keyless 市场列表建立资产主数据与当前流通供应快照；仅保存实际响应字段。
4. 使用 Kraken 和 Coinbase 已实测的公共端点补充跨交易所现货报价；地域性或接口不稳定交易所不作为基础依赖。
5. 资产分类采取小批次、限速、可恢复的同步方式，记录 `partial_rate_limited` 状态；不以抓取网页替代接口。
6. 链上活跃地址、交易和手续费历史采用各链公开节点/浏览器或已有开放聚合源逐链核验；不将需 API key 的 Etherscan、商业聚合器列为基础依赖。
