# 免费数据层扩展来源核验

## 可直接接入的公开历史数据

| 数据 | 来源 | 免费可用字段与边界 |
|---|---|---|
| 永续资金费率历史 | Deribit `public/get_funding_rate_history` | 无认证的公共方法；按 PERPETUAL 合约返回小时级时间戳、1 小时/8 小时利率与指数价格。 |
| OKX 市场与衍生品快照 | OKX Public REST/WebSocket | 公共频道无需认证；可采集行情、K 线、订单簿、标记价格及公开衍生品字段。私有账户数据不属于数据层。 |
| 资产市场元数据 | CoinGecko `/coins/markets` | 文档标注 Demo/Keyless 层存在，返回 coin id、symbol、名称、价格、市值、排名、流通/总/最大供应与更新时间；按 250 个 ID 分页。 |

## 不纳入免费实现的端点

CoinGecko 历史流通供应图端点为 Enterprise Only，不能作为无付费、无密钥数据层来源。它只能作为未来获得授权后的可选补充，当前不会调用。

## 实施优先级

1. 将 Deribit 小时资金费率历史写入独立历史表；不混写为当前快照。
2. 扩展 OKX 公共历史 K 线、资金费率、OI、基差及清算可得字段，并以来源/时间/交易所作联合键。
3. 以 CoinGecko Keyless 市场列表建立资产主数据与当前流通供应快照；仅保存实际响应字段。
4. 链上活跃地址、交易和手续费历史采用各链公开节点/浏览器或已有开放聚合源逐链核验；不将需 API key 的 Etherscan、商业聚合器列为基础依赖。
