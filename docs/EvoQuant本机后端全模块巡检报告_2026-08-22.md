# EvoQuant 本机后端数据覆盖与运行巡检报告

**巡检对象：** Windows 本机 `EvoQuantV3`（`http://127.0.0.1:8001`）  
**最终验证时间：** 2026-08-22  
**验证原则：** 全部采集、计算、数据库审计和状态验证均由项目虚拟环境中的 Python 直接调用；没有采用 PowerShell 输出重定向包装采集或验证。  
**数据库边界：** 持续复用 `exchange_data.db`、`market_data.db` 和 `analytics.db`，未增加数据库服务。

## 一、执行摘要

本轮修复将 EvoQuant 从早期的“5 活跃、8 空、22 报错”推进到 **20 活跃、1 空、14 已禁用、0 报错**。最终状态由 Python 覆盖验证器同时核对实时 `/status/`、`DOMAIN_REGISTRY` 主表映射和 SQLite 实际记录量；四项断言全部通过：没有错误域、预期公开域均有真实主表记录、唯一空域是尚未触发真实事件的异常检测、所有未授权或输入不可靠域均显式禁用。

> **产品结论：** EvoQuant 已具备作为“数字资产研究团队市场情报与风险监测工作台”的真实数据底座。定位应是 **OKX 市场微观结构 + 免费公开宏观、新闻、链上、DeFi、治理、Gas、Mempool、MEV、矿工与稳定币供应快照**，而不是地址归因、鲸鱼画像、全量 ETF 流或社交情绪数据库。

### 3. 已明确禁用的未授权、失效或输入不足域

禁用域默认返回 `disabled`。只有在获得许可并部署经验证的数据契约后，运维人员才可用 `FF_<DOMAIN>_ENABLED=1` 显式开启；仅开启开关不代表具备数据再分发权。

| 数据域 | 禁用原因 | 后续合规路径 |
|---|---|---|
| `etf_flow` | 完整 ETF 流数据需要 SoSoValue 等商业许可证 | 按试点合同采购并记录再分发范围 |
| `exchange_reserve` | 无持续、可验证且可免费再分发的交易所地址归属 | 建立可审计地址标签来源后重启 |
| `sentiment_composite` | 公共情绪成分权重与质量契约未验证 | 明确输入、权重、时效和异常降级后再实现 |
| `liquidity_regime` | 依赖的储备与质押输入尚不可靠 | 不用零值合成中性流动性信号 |
| `token_unlock` | 无稳定、可再分发的免费解锁排程来源 | 获得合法排程源或客户授权后启用 |
| `whale_tracker` | Arkham / Nansen 地址标签通常受商业授权约束 | 按客户合同采购 |
| `whale_pnl` | DeBank Pro 等钱包收益数据受商业授权约束 | 采购后增加账户归属和再分发审计 |

| `nft_market` | 原 Reservoir 集成不可用 | 重新评估需求并选择合规替代源 |
| `dex_trade_flow` | 当前 0x 集成不可用 | 替换为可验证的公开接口后独立接入 |
| `regulatory` | 官方公告采集器尚未实现 | 若有客户需求，以官方源建立新模块 |
| `onchain_address` | Arkham 等地址画像许可受限 | 保持关闭，避免错误实体归因 |
| `derivatives_sentiment` | 缺少稳定、可复现的公共上游 | 以现有资金费率/OI因子替代，不冒充独立数据域 |
| `onchain_holder` | 地址级持仓分布通常依赖商业归因或专门索引 | 采购或从试点范围移除 |

## 四、逐域新鲜度与重启后刷新证据

`scripts/audit_active_domain_freshness.py` 已对 20 个活跃域输出主表记录量、时间列和最新值。服务重启后，OKX 行情、资金费率、订单流和盘口分别刷新至 `03:51–03:52`；技术指标、特征标准化、跨资产和组合风险刷新至 `03:52`。宏观、新闻、链上、期权、DeFi、治理、Gas、Mempool、MEV 与矿工公开采集均在重启后重新运行并推进主表时间；稳定币公共链分布在重启后再次采集到 `03:46:07`。这证明 API 重新加载后，核心市场、公开扩展源与逻辑计算链路均可继续向 SQLite 写入。

> **运行解释：** 本次验证证明“重启后可再次采集并落库”，并不等同于已经部署了长期常驻调度。将任何域对外宣传为近实时前，应先配置、监控并验收其独立刷新频率、超时阈值和失败告警。

## 六、试点产品与持续运行建议

试点产品应优先展示有明确来源、记录量、最新时间和解释边界的活跃域：BTC/ETH 的 OKX 行情、资金费率、OI、订单流、盘口、技术状态、Regime、宏观上下文、新闻标注、DeFi、治理、Gas、Mempool、MEV、矿工及稳定币链分布。研究简报和风险提醒必须附带 `as_of` 时间、来源范围和质量状态。

商业化应围绕团队 Watchlist、可信研究简报、风险解释、告警审计和可追溯数据质量，而非自动交易。地址画像、鲸鱼 PnL、ETF 流、社交情绪和解锁日历等高价值补充能力应作为单独的数据授权附加项：先审查供应商许可、地域可用性和客户再分发权，再启用功能开关。

> **对外可用门槛：** 任何对外展示指标都必须同时具备来源可追溯、真实落库、最新时间可见、API 非 error 和降级原因可解释五项条件。本报告中的空域与禁用域不得在前端中伪装为零值或默认“中性”判断。
